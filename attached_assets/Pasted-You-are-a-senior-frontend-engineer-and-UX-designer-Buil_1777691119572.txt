- Tables (Styled)
- Body Text
- Abstract Block
- Keywords Section
- Grid / Spacing System

➕ Add additional smart elements:

- Numbered lists / bullet styles
- Highlighted quotes
- Image placeholders
- Dividers / separators
- Page numbering styles

---

🎨 For EACH element:

Provide:

1. Toggle (enable/disable)
2. Style options:
   - Font family
   - Font size
   - Font weight
   - Text color
   - Background color
   - Alignment
   - Spacing (margin/padding)
3. “Let AI decide” toggle

🧾 Visual Explanation (IMPORTANT):
